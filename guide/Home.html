    CrabbyTab#

    Welcome to the CrabbyTab wiki. This is the place to learn how to install CrabbyTab, run a debate tournament with it, and work on its code.

    CrabbyTab is a free, open-source debate tabulation system for British Parliamentary, two-team formats (Asian/UADC, Australs, World Schools, APDA, Karl Popper and custom) and N teams per room (for example public speaking). It handles the whole tournament: setup, participant imports, check-ins, draws, adjudicator and venue allocation, ballots, feedback, standings, breaks and elimination rounds, public pages, private URLs and email. Its algorithms follow Tabbycat's. CrabbyTab is an independent project and is not affiliated with Tabbycat.

    Who it is for: tab directors, adjudication cores and organisers who want a capable tab system without paying for or maintaining a server. It runs on Vercel's and Firebase's free tiers.

    How it works, in one paragraph#

    CrabbyTab is local-first. The tab room's working copy lives in the browser (IndexedDB), and draws, allocations, standings and breaks are computed there, so the tab room keeps working on a flaky connection. For cloud tournaments, ballots, check-ins, draws and allocations sync live between administrator devices; other changes go up with Upload, which merges into Firebase Firestore and reports conflicting edits instead of overwriting them. A sanitised, cached snapshot of whatever you have released is then published for the public pages. Participants use private URLs (or optional public forms), which write to the cloud copy through server routes. See Backups, restore and cloud sync and Caching, indexing and performance.

    Status#

    The behaviour described here is what the code on the beta branch does (development is integrated there before release to main). A source-level audit against Tabbycat v2.12.1, a second independent audit and the remaining deliberate differences are summarised on Comparison with Tabbycat and in the parity plan. This wiki is generated from docs/wiki/ in the repository and also published as a browsable guide at https://the-studio-of-sadiq.github.io/crabbytab/.
