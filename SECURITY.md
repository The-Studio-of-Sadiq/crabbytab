# Security Policy

## Supported versions

Security fixes are made for the latest version on the repository's default
branch. No other release line is currently guaranteed to receive security
updates.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's private
vulnerability reporting for this repository (the **Report a vulnerability**
option on the repository's Security tab). Include steps to reproduce, affected
versions or components, and the potential impact. Avoid including real user
data, credentials, or other secrets in a report.

The maintainers will acknowledge and investigate reports as soon as
practicable. Please allow time to assess and address a report before publicly
disclosing it.

If private vulnerability reporting is unavailable, contact the repository
maintainers privately through GitHub.
